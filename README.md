# sovuhara.github.io

Личная страница: https://sovuhara.github.io

Тёмная «сцена» с ночным фоном на SVG, крупная типографика и декоративные
теги разметки. Фон нарисован в самом HTML — картинок для оформления нет.

Статика без сборки, фреймворков и внешних запросов — как и приложения, на которые
она ведёт. Правится руками, публикуется через GitHub Pages из ветки `main`.

## Устройство

| Путь | Что это |
|---|---|
| `index.html` | главная: приветствие и кнопки приложений, одна страница на один экран |
| `dynamic-island/index.html` | страница приложения: описание, скриншоты, установка, терминал |
| `dynamic-island/appcast.json` | манифест обновлений — адрес вставляется в настройках приложения |
| `styles.css` | оформление обеих страниц: общие переменные, затем блок главной, затем блок страницы проекта |
| `app.js` | переключатель языка, демонстрация острова, проявление секций |
| `assets/` | иконки приложений и скриншоты |

Русский текст лежит прямо в разметке, английский — в атрибуте `data-en` того же
элемента. Скрипт просто меняет их местами, поэтому без JS страница остаётся русской
и читаемой.

## Как добавить новое приложение

1. Положить иконку в `assets/` (PNG 512×512 хватит).
2. В `index.html` скопировать блок между комментариями `НОВОЕ ПРИЛОЖЕНИЕ` и поменять
   иконку, название, описание и адрес папки.
3. Скопировать папку `dynamic-island/` под новым именем и переписать содержимое
   `index.html`: заголовок, описание, скриншоты, ссылку на релиз.
4. Скриншоты положить в `assets/shots/`, у каждой картинки проставить `width` и
   `height` — иначе страница дёргается при загрузке.

## Как обновить приложение после нового релиза

1. В репозитории приложения выпустить релиз: `Tools/release.sh` соберёт универсальный
   `build/DynamicIsland.zip` и напечатает sha256.
2. В `dynamic-island/appcast.json` поправить `version`, `notes`, `url` (тег релиза)
   и `sha256`.
3. На странице проекта поменять номер версии и размер в строке под кнопками.

Кнопка «Скачать» ведёт на `releases/latest/download/DynamicIsland.zip` и сама
показывает последний релиз — её трогать не нужно.
